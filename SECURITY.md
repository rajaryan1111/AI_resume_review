# Security Policy

## Scope

This project processes resumes and job descriptions. Do not commit real resumes containing personal information, credentials, API keys, production database exports, or private candidate data.

## Reporting a vulnerability

Please report security vulnerabilities privately through the maintainer's GitHub profile rather than a public issue. Include affected files, reproduction steps, and impact.

## Data handling

Use environment variables for configuration. Prefer synthetic or redacted documents for demos and tests. Candidate information should not be treated as public test data.
