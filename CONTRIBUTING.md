# Contributing

Thanks for contributing to AI Resume Review.

## Development principles

- Keep resume and job-description processing transparent and reproducible.
- Do not commit real candidate resumes, personal information, API keys, or production data.
- Keep frontend, backend, and database responsibilities separated.
- Add regression coverage when changing parsing, scoring, skill-gap analysis, or API contracts.

## Pull requests

Describe the user-facing change, technical components affected, validation performed, and any configuration changes. Include screenshots for meaningful UI changes.
